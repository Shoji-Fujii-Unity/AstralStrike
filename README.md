## English

### Overview

Astral Strike is a 3D shooting game made with Three.js.  
It can be played in a web browser on both PC and smartphone.

The game is designed for landscape screens.  
On smartphones, please rotate the device to horizontal orientation.

### Features

- Three.js based 3D shooter
- Playable on PC and mobile browser
- Landscape-oriented gameplay
- Sound on / off switch
- Local save data using browser storage
- Multi-language interface
- Stage selection
- Stage progression and unlock system
- High score saving per stage
- Many enemy types
- Many boss types
- Multiple stage waves
- Boss attacks including fan fire, ring fire, spiral fire, charge, teleport, and enemy summoning

### Supported languages

The game supports the following languages:

- English
- Japanese
- Chinese

The language can be selected from the title screen.

### Controls

#### PC

- WASD or arrow keys: move
- Mouse: aim
- Mouse click or Space: fire
- Esc or P: pause

#### Smartphone

- Use the screen in landscape mode.
- Left side of the screen: move
- Right side of the screen: aim and fire

On touch devices, the right-side control provides an aiming joystick.  
Aiming toward that direction triggers firing.

### Save data

Game progress, unlocked stages, high scores, sound settings, and language settings are saved locally in the browser.

This game does not require a server account.  
Saved data is kept on the user's device browser.

### Notes

This project is intended to run as a browser game.  
Network access may be required if external libraries are loaded from a CDN.

If the game fails to start, check that the JavaScript libraries are loaded correctly and that the browser supports WebGL.

このゲームは次の言語に対応しています。

- 英語
- 日本語
- 中国語

言語はタイトル画面から切り替えることができます。

### 操作方法

#### PC の場合

- WASD または矢印キー: 移動
- マウス: 狙い付け
- マウスクリック または スペースキー: 射撃
- Esc または P: ポーズ

#### スマートフォンの場合

- 横画面で操作してください。
- 画面左側: 移動
- 画面右側: 狙いと射撃

タッチ端末では、右側に仮想ジョイスティックが表示されます。

サーバー上のアカウントは必要ありません。  
セーブデータは使用する端末のブラウザ内に保持されます。

### 補足

このプロジェクトはブラウザゲームとして動作することを想定しています。  
外部ライブラリを CDN 経由で読み込んでいる場合、ゲーム開始にはネットワーク接続が必要です。

ゲームが起動しない場合は、JavaScript ライブラリが正しく読み込まれているか、ブラウザが WebGL に対応しているかを確認してください。

## 中文

### 概述

Astral Strike 是使用 Three.js 开发的 3D 射击游戏。  
它可以在 PC 和智能手机的浏览器中游玩。

游戏采用横屏设计。  
使用智能手机时，请将设备旋转为横向显示。

### 功能

- 基于 Three.js 的 3D 射击游戏
- 支持 PC 与移动端浏览器
- 横屏游玩设计
- 音效开启 / 关闭功能
- 使用浏览器本地存储保存数据
- 多语言界面
- 关卡选择
- 关卡解锁与进度保存
- 每个关卡的最高分保存
- 多种敌人类型
- 多种 Boss 类型
- 多波次关卡
- Boss 攻击包括扇形弹幕、环形弹幕、螺旋弹幕、冲锋、瞬移、召唤小怪等

### 支持语言

游戏支持以下语言：

- 英语
- 日语
- 中文

可以在标题界面切换语言。

### 操作方式

#### PC

- WASD 或方向键：移动
- 鼠标：瞄准
- 鼠标点击或空格：射击
- Esc 或 P：暂停

#### 智能手机

- 请横向使用设备。
- 屏幕左侧：移动
- 屏幕右侧：瞄准与射击

在触屏设备上，右侧会显示虚拟摇杆。  
朝向该方向即可确定攻击方向并射击。

### 存档数据

游戏进度、已解锁关卡、最高分、音效设置和语言设置都会保存在浏览器的本地存储中。

本游戏不需要服务器账号。  
存档数据会保留在使用该设备的浏览器内。

### 说明

本项目以在浏览器中运行作为目标。  
如果外部库通过 CDN 加载，则开始游戏时需要网络连接。

如果游戏无法启动，请检查 JavaScript 库是否正确加载，以及浏览器是否支持 WebGL。
